## 已修复 P0

1. **kernel health/disabled/observers 并发 map/slice 读写**
   - 增加 <code>stateMu</code> / <code>healthMu</code> / <code>engineMu</code>；<code>buildEngine</code> 原子替换 engine+observers；<code>HandleEvent</code> 只取一次快照。
   - WebUI 轮询状态与插件启停并发不再触发 <code>concurrent map writes</code>。
2. **Scheduler 关闭死锁 / 无界阻塞**
   - 重写会话队列：关闭用 <code>done</code> + active 计数 + 条件变量；Submit 非阻塞，队列满返回 <code>ErrBackpressure</code>；Close 先拒绝新提交、排空已入队事件、再等 worker。
   - 调度器使用独立生命周期，收到 SIGTERM 后由 Stop 排空，不随 signal ctx 立即丢队列。
3. **queue.Pool 关闭/提交死锁**
   - 同样改为 closed/done/active 状态机；Close 解除阻塞中的 Submit，再关闭 jobs；panic 恢复保留。

## 已修复 P1

- kernel：<code>startedIDs</code>/<code>disabled</code>/<code>health</code> 全部加锁；Engine 读取加锁；Start 跳过 disabled；Register 在 Init 后拒绝；禁用插件从 startedIDs 移除；Stop 不再二次 Stop 已禁用插件；Stop 后清空 engine。
- OneBot：<code>at.qq</code> 兼容 int64/float64/json.Number/string，9 位 QQ 不再变科学计数法；丢弃自身消息；MessageID=0 时用时间戳兜底，减少 EventID 撞车。
- kernel 入站去重：EventID + TTL + 容量上限，重复事件直接 silent。
- SQLite：busy_timeout/foreign_keys/journal_mode 写入 DSN，连接池每条连接都生效；文件/内存库均处理。
- WebUI：
  - 旧/新 WebUI 启动先 <code>net.Listen</code>，端口失败返回 error；旧 WebUI 非 loopback + 空 token 拒绝启动。
  - auth 加常量时间比较；空 token 时新插件禁止写接口，旧 WebUI 写接口校验 Origin；POST/PUT 等写操作不再跨站放行。
  - 插件配置写入先 YAML 校验，再临时文件 + rename，0600；禁止从 WebUI 写绝对路径的 <code>llm_config_file</code>。
  - WebUI 不能停用自身；toggle 使用独立 30s ctx，避免客户端断开取消插件 init。
- 插件配置：<code>kernel.yaml</code> 启动期启停、critical 插件校验；<code>-migrate-config</code> 不覆盖已有插件文件。
- provider 密钥：provider 显式 api_key 优先，轮换立即生效；写回不再用已解析值覆盖，主配置/ provider 写入失败时回滚。
- session：Acquire/Release 引用计数，Cleanup 与取锁之间的 TOCTOU 已消除（handler 使用 Acquire）。
- 异步插件：统一 <code>async.Group</code>，Stop 先 closed 再等待，Add/Wait 不再竞争；goroutine panic 有 recover；summarizer 的 inflight 在 panic 时也会清理。
- tool：结果按 UTF-8 边界截断；工具 panic 转 sdk.Error；管理工具要求 admin；manifest 声明的工具名/权限参与校验。
- LLM/action：新增内核超时；工具/动作/adapter 调用 panic 恢复；降低工具参数/结果日志级别。
- meme：下载超时、大小/Content-Type 校验、重定向校验；默认拒绝私网地址，测试/内网可显式 <code>WithAllowPrivate</code>。
- manifest：kind 白名单、requires 去重、工具 timeout、schema/manual 路径不得逃逸。
- 旧 Manager：Start 失败回滚已 Init 插件；Stop 收集错误后继续停后续插件；SetEnabled 运行期会真正 Init/Stop 插件。
- 旧 app：manager.Stop 加 30s 超时；新 runtime dry_run 直接拒绝启动，避免误发真实消息。
- Host 隔离：<code>Host.Tools</code> 按 manifest 工具白名单裁剪；<code>Host.Actions</code> 需要 <code>messaging.send</code>；<code>Storage</code> 强制插件命名空间；<code>LLM/Memory/Vision/Members/Memes</code> 均按 manifest permissions 门控，缺权限返回 nil/权限错误。
- manifest 工具声明参与运行期校验：工具名/权限必须一致，TimeoutMS 会作为默认超时；新增 admin read_manual 与 WebUI 工具手册/Schema 查询。
- Scheduler 不再继承 signal ctx，SIGTERM 后由 Stop 排空；新增 handler/qq/sdk 直接测试。
- queue.Pool 增加 <code>CloseWithContext</code> 与 <code>TrySubmit</code>；旧 app 收到事件时队列满会丢弃并告警，不再让 adapter 回调堆 goroutine。
- Host 无 Bus/Memory 时返回 no-op 实现，避免插件空指针 panic；工具声明与 timeout 参与运行期校验。
- Scheduler 增加空闲会话队列 janitor（默认 10m，可配置），避免会话数线性泄漏 goroutine/channel。
- WebUI 插件配置保存后调用 ReloadPlugin（停用→启用）应用新配置；关键插件/自身会返回 reload 错误。
- Trace 补记工具调用与延迟；ContextProvider.Budget 真正参与上下文预算。
- 新增 OutputPolicy，Safety 在发送前检查模型回复，避免违禁词只拦入站不拦出站。
- summarizer 在 LLM 失败时保留历史，不再因为一次超时丢掉整段群聊；只有成功后才裁剪已总结部分。
- QQ Client 支持 Close 后重新 Connect（重置 closeOnce）；Scheduler Close 等待 janitor 退出，避免关闭后仍扫描队列。
- OneBot 首次连接失败改为指数退避重试，不再因 NapCat 尚未就绪直接退出；发送改为等待 API echo 并检查 retcode，不再静默成功。
- WebUI config 写操作加互斥，避免两个管理员同时保存造成 main/llm 混搭；LLM 重试分类改为状态码上下文匹配；主配置 raw 保存通过 YAML Node 保留注释并恢复脱敏密钥（包括用户删除的字段），且不会把 llm/vlm 重新混入拆分后的 main 配置。
- config.Reload 监听器 panic 现在返回错误并在提交新配置前中止；WebUI 可据错误恢复文件。
